# SoapCraft editorial package system

A versioned package, not a bot chat or loose draft, is the unit of editorial work. It owns the intent, evidence, claims, article, independent review, release evidence, and measurement baseline.

```text
observed -> diagnosed -> researching -> drafted -> review_required
-> approved -> release_verified -> published -> measuring
-> improved | consolidated | retired
```

Agents make editorial judgments: intent, evidence, premise, writing, review, and portfolio decisions. Scripts import signals, validate, render, publish an already-approved record, and audit. Scripts never write copy, choose topics, or silently publish.

Legacy articles are not grandfathered. A page without a complete contract is excluded from public blog listings, routes, and the sitemap until rewritten.
